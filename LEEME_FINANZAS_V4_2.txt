CRM VISAS V4.2 — AJUSTES FINALES DE CONTROL DE INGRESOS
==========================================================

CAMBIOS INCLUIDOS
-----------------
1. VARIAS VENTAS PARA EL MISMO CLIENTE / SOLICITUD
   - Una solicitud ya NO queda limitada a una sola venta.
   - El mismo cliente puede comprar Visa + Acta de Nacimiento + Copias + otro servicio.
   - Cada servicio nuevo se registra como una NUEVA VENTA.
   - Los abonos siguen registrándose sobre la venta correspondiente.
   - Se eliminó el índice único que impedía más de una venta por application_id.

2. FOLIO DE VENTA AUTOMÁTICO
   - Cada venta recibe un folio automático:
     VTA-AAAA-NNNNNN
     Ejemplo: VTA-2026-000001
   - La asesora no captura ni calcula ese folio.
   - El folio de solicitud VISA-... continúa funcionando por separado.

3. CATÁLOGO MAESTRO ADMINISTRABLE
   - Sólo Administrador puede:
     * Crear conceptos.
     * Editar categoría, concepto, precio, modalidad y notas.
     * Activar.
     * Suspender temporalmente.
     * Desactivar.
   - Los códigos ING-XXX nuevos se generan automáticamente.
   - ACTIVO: aparece a las asesoras.
   - SUSPENDIDO: se conserva, pero temporalmente no puede venderse.
   - INACTIVO: permanece como histórico, pero no puede venderse.
   - Un concepto ACTIVO debe tener precio autorizado mayor a $0.

4. CORRECCIÓN DEL DOBLE DE VENTAS EN BALANCE
   - El Balance ya no multiplica el valor de una venta por el número de pagos.
   - Ejemplo corregido:
     Venta: $6,520
     Pago 1: $3,000
     Pago 2: $3,520
     VENDIDO = $6,520
     COBRADO = $6,520
     NO $13,040.
   - También se corrigieron las exportaciones por asesora y por servicio.

5. CIERRE SEMANAL
   - La semana sigue siendo lunes a viernes.
   - No se puede cerrar antes del viernes correspondiente.
   - El botón aparece bloqueado antes de la fecha.
   - También existe validación de servidor: aunque alguien intente enviar
     el formulario manualmente, el cierre anticipado se rechaza.
   - En viernes o después sí puede cerrarse si no existen pagos pendientes.

6. REPORTES / VISTAS
   - "Trámites vendidos" se sustituyó por "Ventas" donde corresponde.
   - Se muestra el folio VTA-... para distinguir varias ventas del mismo cliente.
   - Cuentas por cobrar y exportaciones también distinguen folio de venta.

PRUEBA RECOMENDADA
------------------
A. VENTAS MÚLTIPLES
1. Entrar como asesora.
2. Elegir Santi.
3. Registrar "Visa americana primera vez con transporte".
4. Confirmar que recibe folio VTA-2026-000001 (o el siguiente disponible).
5. Volver a Registrar ventas.
6. Elegir nuevamente a Santi.
7. Registrar "Acta de nacimiento".
8. Deben existir DOS ventas independientes para el mismo expediente.

B. ABONOS
1. Seleccionar una de las ventas con saldo.
2. Desde Control de Ingresos registrar el abono en ESA venta.
3. El abono no debe modificar el saldo de la otra venta.

C. BALANCE
1. Registrar una venta de $6,520 con:
   $3,000 efectivo
   $3,520 terminal/tarjeta
2. Validar ambos pagos.
3. Balance Semanal debe mostrar:
   Ventas contratadas: $6,520
   Dinero recibido:    $6,520
   Efectivo:           $3,000
   Terminal/Tarjeta:   $3,520
   Ventas por asesora: vendido $6,520 / cobrado $6,520

D. CIERRE
Antes del viernes el sistema debe mostrar:
"Cierre disponible a partir del viernes ..."
y no permitir cerrar.
